An open-world crime game a la GTA 6, built for [make.fun's gta6-01 bounty](https://make.fun/bounty/gta6-01): a living city with cars, traffic and pedestrians, wanted levels with police pursuit, missions and story, combat, HUD and minimap, start menu and save. All procedural, no network, no assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
