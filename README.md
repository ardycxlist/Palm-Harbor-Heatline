Palm Harbor: Heatline is an open-world crime game in the spirit of GTA 6, built for make.fun's gta6-01 bounty. The city is alive: cars drive the streets, traffic flows, pedestrians walk the sidewalks, and once your wanted level climbs the police come after you — on foot, in cars, and by helicopter. Take on missions, follow the story, fight when you have to, and keep an eye on the HUD and the minimap. A start menu and a save system round it out. Everything is procedural — no network requests, no downloaded assets, just code.

## Run it

Needs Node.js 22 or later. Start the local server:

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse.
